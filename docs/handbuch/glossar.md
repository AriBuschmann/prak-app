# Glossar

| Begriff            | Erklärung                                                                 |
|--------------------|---------------------------------------------------------------------------|
| Beitragskonto      | Übersicht über fällige Beiträge, Zahlungen und Saldo eines Vertrags       |
| Fälligkeit         | Tag, an dem ein Monatsbeitrag bezahlt sein muss                           |
| Guthaben           | Kunde hat mehr bezahlt als fällig war (Saldo negativ)                     |
| Kündigungsfrist    | Zeit zwischen Eingang der Kündigung und frühestem Vertragsende            |
| Mindestlaufzeit    | Zeit ab Vertragsbeginn, vor deren Ablauf der Vertrag nicht enden kann     |
| Monatsbeitrag      | Betrag, den der Kunde pro Monat für einen Vertrag zahlt                   |
| Rückstand          | Fällige, aber noch nicht bezahlte Beiträge (Saldo positiv)                |
| Saldo              | Soll minus bezahlt                                                        |
| Soll               | Summe aller bis heute fälligen Beiträge                                   |
| Tarif              | Vertragsart mit festen Regeln (Mindestlaufzeit, Kündigungsfrist)          |
| Valuta             | Datum, an dem eine Gutschrift auf dem Konto wirksam wird                  |
| Verwendungszweck   | Text der Überweisung, enthält meist die Vertragsnummer                    |
